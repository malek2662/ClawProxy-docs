System Prompt Control

Grab every agent by its system prompt

Define a rule once and ClawRouter rewrites the system prompt of every matching request — before translation, before it reaches the provider. Prepend, append, replace, or surgically patch a single sentence inside a 20,000-token prompt. Conversation messages and tool definitions always pass through untouched.

  • Scope rules per client, per provider, or per combo — they compose in order, one place for all your traffic
  • Structurally surgical: messages and tools[] can never be affected
  • Works across all 4 API formats — prompt-cache friendly, byte-identical when no rule matches
